# Community Troubleshooting

Use the
[canonical troubleshooting guide](https://github.com/tylermowll/countscape/blob/main/docs/troubleshooting.md)
first. This page is a community-maintained symptom index, not a second source of
commands or recovery policy.

| Symptom | Start with |
|---|---|
| Config missing or target rejected | Canonical sections “Configuration does not exist” and “Target and timezone disagree” |
| No usable photo | “No usable photos” |
| Mutter or session-bus failure | “Mutter display discovery fails” |
| Crop, scale, portrait, or monitor-order issue | “The layout or crop looks wrong” and [[Display Recipes]] |
| Timer inactive | “The timer is inactive” |
| Service failed | “A service run failed” |
| Timer ran but wallpaper did not visibly change | “Nothing changed after a timer run” |
| Concurrent-operation error | “Another operation is already running” |
| Uninstall stopped safely | “Uninstall stops before cleanup” |
| Nondefault XDG roots | “Custom XDG roots do not match” |

## Ask the community

Follow the [support policy](https://github.com/tylermowll/countscape/blob/main/SUPPORT.md)
and open a [public issue](https://github.com/tylermowll/countscape/issues/new/choose).
Use the smallest synthetic reproduction possible and redact every diagnostic or
journal line. See [[Privacy]].

Published wiki editing is collaborator-only. Propose additions in an issue and
link the canonical troubleshooting section they complement. Vulnerabilities do
not belong in community troubleshooting; use the private
[security process](https://github.com/tylermowll/countscape/blob/main/SECURITY.md).
