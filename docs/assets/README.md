# Documentation Assets

`countscape-hero.webp` is marketing artwork, not Countscape runtime output. It
was generated on 2026-08-22 with OpenAI's built-in image generation from an
original prompt, with no source or reference images. The scene is entirely
synthetic and contains no people, event data, readable text, dates, or logos.
The delivered image was converted to metadata-stripped WebP for the repository.
