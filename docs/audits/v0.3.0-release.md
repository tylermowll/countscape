# v0.3.0 release validation

Date: 2026-10-29.

## Candidate and automated checks

The date-and-message feature was reviewed in
[PR #22](https://github.com/tylermowll/countscape/pull/22), merged as
`77e5d9fff7fb1ab8f2a41f32d21e462e249b3df2`.

A clean clone passed locked environment synchronization, formatting, lint,
local Markdown links, full-history privacy, and all **409 tests** with **90.72%
coverage** under Python 3.15.2. Wheel and source-archive identity and privacy
checks passed. GitHub CI and CodeQL passed for the feature PR.

Automated coverage includes target-free date initialization, strict IANA zone
and message validation, existing countdown compatibility, mode round trips,
private-data redaction, local midnight within a UTC refresh bucket, fractional
offsets, both DST transitions, backward clocks, suspend-like jumps, independent
photo rotation, long Unicode text, and unchanged-render reuse. Fake-adapter
lifecycle tests cover date-only installation and uninstall, independent URI
restoration, ownership continuity, source/config preservation, and rollback by
restoring compatible private configuration.

## Subsequent live supported-host baseline

The built candidate was installed into the persistent tool environment on
Ubuntu 26.04 GNOME/Wayland, using Python 3.15.2 and Pillow 13.0.0. The tested
layout had two logical monitors with a physical transform, without scaling or
mirroring. No raw display state, private configuration, source photos, rendered
wallpaper, or screenshot is included in this record.

The following checks passed:

- Date-only initialization with an explicit message and IANA timezone, without
  an event target, followed by diagnostics and rendering under private
  temporary XDG roots.
- A private configuration backup before enabling date mode in the existing
  installation. The retained event, source/storage/state paths, ownership seed,
  installation identity, and other settings were preserved.
- Rendering and activation of the current local date and a custom Unicode
  heart message using a system font that contains the glyphs.
- User confirmation that the date and hearts look correct on both monitors.
- Regenerated installed-package units with matching ownership digests, active
  user timer, and an automatic service run with successful exit status.
- Both light and dark GNOME wallpaper URIs matching the generated output in
  spanning mode.
- A natural two-minute photo rotation while the displayed date/message stayed
  unchanged, followed by a natural minute-level wake that reused the output,
  render state, GNOME state, and settings without rewriting them.
- Source-photo byte hashes unchanged throughout the deployment and checks.

The candidate wheel tested in the live session has SHA-256
`88f9f6f878255a56449e56d2effb502167c26609c262882c64f87710b103a0a7`.

The installer also correctly refused an initial test-wrapper attempt that
selected the editable checkout command. The prior package and configuration
were restored before the successful check used the persistent installed
executable.

not establish new live scaling, mirroring, suspend/resume, or rollback/uninstall
coverage; those paths retain their separate recorded or automated evidence.
